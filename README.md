# 🛡️ AI-Based Conversation Risk Detection

## Project Overview

AI-Based Conversation Risk Detection is a Text and Speech Analysis project designed to identify potentially risky communication patterns from conversation text.

The system analyzes conversations and detects indicators such as:

- Threats
- Aggression
- Harassment
- Manipulation
- Coercion
- Fraud
- Suspicious requests
- Sensitive information requests

The application generates an overall conversation risk score and presents the results through an interactive dashboard.

## Objectives

1. Analyze conversation text automatically.
2. Identify potentially risky communication patterns.
3. Classify different types of conversation risks.
4. Generate an overall risk score.
5. Provide visual analytics.
6. Support early identification of suspicious conversations.
7. Create a foundation for advanced AI-based risk detection.

---

## Main Features

### 1. Conversation Analyzer

Users can enter or paste conversation text into the analyzer.

### 2. Threat Detection

The system identifies potentially threatening language.

Examples:

- "I will hurt you."
- "You will regret this."
- "There will be consequences."

### 3. Aggression Detection

The system identifies aggressive and hostile communication.

### 4. Manipulation Detection

The system looks for pressure, coercion and manipulation patterns.

### 5. Fraud Detection

The system can identify suspicious financial requests and attempts to collect sensitive information.

### 6. Risk Scoring

The system calculates an overall risk percentage.

Example:

```text
Risk Score: 78%
Risk Level: High Risk
